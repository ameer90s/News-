# مرصد الإمارات الذكي

مشروع FastAPI جاهز للرفع إلى GitHub ثم Vercel.

## مهم قبل الرفع
- ملف التشغيل الرئيسي هو `main.py` ويجب أن يكون في جذر المستودع.
- تطبيق FastAPI هو `main:app`.
- لا ترفع هذا المشروع فوق ملفات قديمة بدون حذفها أولًا.
- الأفضل استخدام Repository جديد فارغ، أو حذف كل ملفات المستودع الحالي ثم رفع محتويات هذا المجلد.

## متغيرات Vercel
- `GEMINI_API_KEY` اختياري للتحليل الذكي.
- `GEMINI_MODEL` اختياري. الافتراضي: `gemini-flash-latest`.

## فحص سريع بعد النشر
افتح:
- `/api/health` ويجب أن ترى `"entrypoint":"main.py"` و `"app":"main:app"`.
- `/` لفتح الواجهة.

## هيكل المشروع
كل الملفات المطلوبة موجودة داخل هذا المجلد فقط.
