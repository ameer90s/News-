# مرصد الإمارات الذكي — Flat GitHub/Vercel Build

هذه الحزمة لا تحتوي أي مجلدات فرعية. كل ملفات المشروع موجودة في مستوى واحد.

ارفع جميع الملفات الظاهرة داخل هذا المجلد مباشرة إلى جذر مستودع GitHub.

المتغير المطلوب في Vercel للذكاء الاصطناعي:
- `GEMINI_API_KEY`

اختياري:
- `GEMINI_MODEL`

نقطة تشغيل FastAPI: `main.py` / `main:app`.
